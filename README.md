# White Wine Quality Analysis

This repository explores machine learning classification using the White Wine Quality dataset from the UCI Machine Learning Repository. The goal is to predict wine quality based on physicochemical properties such as alcohol, acidity, sugar, and density.

# Content 
- ✅ White Wine Quality Dataset
- ✅ Data Exploration and Visualization
- ✅ Data Preprocessing and Standardization
- ✅ Logistic Regression Model
- ✅ Jupyter Notebook and Python Source Files
